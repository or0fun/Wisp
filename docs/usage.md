# 使用与配置指南

[返回项目首页](../README.md)

应用名称为 Wisp。由 PersonalAI 更新后，已有设置、剪贴板历史和钥匙串密钥继续沿用；数据目录与 Bundle ID 保留旧值以兼容。

## 快捷操作

| 操作 | 默认快捷键 |
| --- | --- |
| 打开快捷动作 | `⌥Space` |
| 打开剪贴板历史 | `⌥⌘V` |
| 打开工作流程 | `⌥⌘Space` |
| 面板中切换动作 / 剪贴板 / 流程 | `⌘1` / `⌘2` / `⌘3` |
| 选择 / 执行 | `↑↓` / `Return` |
| 首页前后切换三列 | `Tab` / `Shift Tab` |
| 输入换行 | `Shift Return` |
| 收起面板 | `Esc` |
| 设置 / 保存设置 | `⌘,` / `⌘S` |
| 剪贴板中置顶 / 删除 | `⌘P` / `⌘Delete` |

从菜单栏进入设置可录制全局快捷键。冲突时保留原有可用快捷键，并显示错误。每个工作流程也可绑定独立快捷键，直接打开该流程的输入框。

首页采用三列布局：快捷动作（本机应用、AI、网页搜索和实时计算）、工作流程、文件搜索。三列共用输入内容、分别滚动；上下键在当前列循环选择，Tab 向后切列，Shift Tab 向前切列，空列会跳过。回车打开或执行选中项。输入 `g 内容` 或 `json 内容` 等关键词时优先匹配对应入口，并暂停本机搜索。单独的「工作流程」页和独立流程快捷键继续可用。

### 连续按键

设置中每个快捷键均可选择「组合键」或「连续按键」。连续模式下先按下并松开第一个键，再按第二个键：同键两次为双击（如 `⌘ → ⌘`），不同键为顺序输入（如 `⌥ → Space`）。左右两侧的同类修饰键视为同一种键。默认最大间隔 400 ms，可调整为 200 ms–1 秒。

需要完整按下/松开；长按重复不会触发，单键按住超过 500 ms 不计为点击。其他按键、鼠标点击/滚动、应用切换会中断匹配，安全输入开启时不匹配。连续按键不会阻止输入传给当前应用，建议使用修饰键双击，避免与打字冲突。连续按键中使用的组合键不能与已注册的组合快捷键相同。

跨应用识别连续按键需要在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Wisp；未授权时仅本应用内生效，原有组合快捷键照常使用。授权后会自动重新检查监听状态。按键识别不保存键入内容或发送键盘数据。

### 配置引导与后台诊断

首次启动通过三步引导查看快捷键、检查后台权限、连接可选 AI 工具。主面板问号、菜单栏「配置引导与后台诊断」、设置左侧导航底部「配置引导」、设置 → 通用都可重新打开；导航入口从「快捷入口」第一步开始。跳过或完成引导只保存进度，不代表权限已生效；启用需要权限的功能而尚未授权时会显示引导和主面板提示。进入引导不会丢失设置草稿。

「后台唤起」页分别显示系统实际授权、全局监听、安全输入状态，并提供当前应用路径、Finder 定位和正确的系统授权入口。点击「开始后台唤起测试」会收起窗口并切换到其他应用；20 秒内按下当前快捷动作快捷键，只有实际从后台触发该快捷键才算通过。预览模式不执行后台测试。

**开关已开、重启后仍不生效：** 返回引导检查「系统实际授权」。若仍显示未生效，在「系统设置 → 隐私与安全性 → 辅助功能」移除旧 PersonalAI / Wisp 条目，用「＋」重新添加 `/Applications/Wisp.app` 并开启，再退出并重新打开应用。以引导中的实际状态和后台测试结果为准。

默认本地构建使用 ad-hoc 临时签名，更新后代码哈希变化可能导致旧权限失效。正式分发应使用固定开发者签名，可指定本机已有的签名身份：

```bash
WISP_SIGNING_IDENTITY='Developer ID Application: Your Name (TEAMID)' ./scripts/build-app.sh release
```

构建脚本也兼容旧版 `PERSONALAI_SIGNING_IDENTITY` 和 `PERSONALAI_DISABLE_SPM_SANDBOX` 参数，新参数优先。脚本不会创建证书或更改系统授权。缺少有效签名身份时，请按引导对更新后的应用重新授权。引导进度单独保存在本地 `setup.json`，不含密钥或按键内容。

## 本机应用与文件搜索

- **应用**：输入应用名，在「快捷动作」列选择应用并打开。支持应用显示名、原始名称与 Bundle ID 的不区分大小写匹配，最多显示 12 个结果。标准安装目录（含子目录）为 `/Applications`、`/System/Applications` 和 `~/Applications`；列表缓存约一分钟，后续输入时刷新，不依赖应用是否被 Spotlight 收录。
- **文件与文件夹**：在第三列按文件名查找，使用 macOS 的本机 Spotlight 索引，不搜索正文，也不逐次遍历磁盘。搜索在输入停顿约 200 ms 后开始，名称完全匹配和前缀匹配优先，最多显示 40 项；有更多候选时显示「40+」，可继续补全名称缩小范围。
- **打开与定位**：点击或回车用默认应用打开文件，文件夹在 Finder 中打开；右键菜单可选择「在 Finder 中显示」。结果同时显示所在目录，帮助区分同名文件。项目被移动或删除时会提示重新搜索。
- **范围与限制**：查询系统索引内的本机卷，过滤隐藏路径、应用包内部、常见依赖目录及系统与用户 Library 等资源目录。Spotlight 隐私排除、尚未索引、没有读取权限和未挂载磁盘上的项目可能不可见。候选提取有上限，宽泛名称请进一步细化。索引不可用或查询超时时会显示说明，不会自动更改系统索引或隐私权限。
- **输入与选择**：未手动选择时，匹配的应用优先选中；没有应用命中时优先选中文件，计算结果和快捷关键词保留优先级。本机查询在后台运行，不会向 AI 或搜索网站发送文件名。只有主动选择 AI／网页搜索动作才会执行对应的外部操作。异步结果刷新会保留主动选中的项目；选中项目消失时清除选择，避免回车误开另一项。

## 实时计算

主界面输入 `3+4` 会在列表首位显示 `7`，点击结果或按回车复制。支持 `+ - * /`、`× ÷`、括号（含中文括号）、小数、负数、`^` 幂、后缀 `%` 百分数和科学计数法；例如 `100*20%` 得 `20`，`(3+4)*2` 得 `14`。也可用 `=` 前缀明确进入计算，如 `=42`。

除零、溢出或未完成的公式会显示提示。普通文字仍进入 AI / 搜索 / 流程动作列表。计算使用本地数学解析器，不执行脚本或联网；采用浮点运算，显示最多 15 位有效数字。

## 剪贴板历史

- 记录文本、图片和文件引用；支持搜索内容或来源应用、去重、置顶、删除与预览。
- 列表顶部可切换「全部、文字、图片、文件」，打开剪贴板时默认显示全部。切换分类保留搜索词，并选中该分类的首条结果；搜索、方向键和预览均在当前分类内生效。图片分类保存图片内容，文件分类保存文件引用（包括在 Finder 中复制的图片文件）。清空历史仍清空全部分类。
- 默认保留 300 条、30 天。总容量上限 256 MB；单条文本最大 2 MB，图片最大 20 MB。置顶不受天数限制，仍计入数量和容量上限。
- 回车默认恢复到系统剪贴板。开启「粘贴到原应用」并授予辅助功能权限后，会恢复原应用焦点并发送 `⌘V`。
- 支持暂停、彻底关闭记录、按 Bundle ID 排除应用。跳过带 Concealed / Transient / AutoGenerated 标记的内容；没有这些标记的敏感文本仍可能被记录。
- 文件历史保存路径引用，原文件移动或删除后无法恢复。暂不保留富文本格式，不提供 OCR。
- 从应用启动后的下一次复制开始采集；macOS 对剪贴板读取的系统限制仍然适用。

数据位于 `~/Library/Application Support/PersonalAI/`，以本地 JSON 和 PNG 存储，目录权限 `0700`、文件权限 `0600`，没有加密或同步。损坏的 JSON 会备份为 `.corrupt-*`；损坏的剪贴板历史不会自动覆盖或清理图片，可从备份恢复，或明确清空后重建。

## AI 与搜索

输入内容，通过上下键选择豆包、Codex 或搜索引擎，回车执行。

主界面也直接显示已启用的工作流程。输入内容后选择流程即可继续处理，无需切换面板；未启用的流程不显示。

**豆包：** 默认打开 `https://www.doubao.com/chat/`，同时把输入复制到剪贴板，在豆包输入框按 `⌘V` 后发送。可在设置中选择本机豆包应用；开启自动粘贴并授予辅助功能权限后，会在所选应用前台时尝试粘贴。自动粘贴取决于目标应用的输入焦点，需要检查后发送。网页模式通过剪贴板传递输入，不自动提交聊天。

另提供可选的火山方舟 Chat Completions API 模式：设置 HTTPS 地址、Model / Endpoint ID 和 API Key，即可在面板内显示结果。API Key 存入系统钥匙串，配置 JSON 不含密钥。

**Codex：** 自动发现 Homebrew、PATH 或本机 Codex / ChatGPT 应用中的 CLI，也可设置绝对路径。先在终端完成 `codex login`。通过 `codex exec`、stdin 和输出文件获取结果，使用独立临时工作目录、`read-only` 沙箱及 `--ephemeral`。支持配置模型和超时，当前 CLI 需要支持这些参数。登录、网络或 CLI 错误会显示在面板中。

**搜索：** 内置 Google、百度、GitHub，可添加、修改或删除搜索引擎。URL 必须包含 `{query}`，例如：

```text
https://www.google.com/search?q={query}
```

输入 `g macOS clipboard` 可直接选中 Google；关键词也支持流程，例如 `json {"hello":"world"}`。输入会经过 URL 编码。

## 自定义工作流程

在「设置 → 工作流程」中新建并配置：

1. 名称、关键词、说明、可选独立快捷键。
2. 工作目录、整个流程超时、是否自动复制最终结果。
3. 一个或多个脚本步骤，每步设置解释器绝对路径和脚本，可调整顺序。

第一步的 stdin 是用户输入；之后每一步的 stdin 是前一步 stdout。不超过 32,000 字节的输入还会写入环境变量 `WISP_INPUT`（兼容旧名 `PERSONALAI_INPUT`）；更大的输入仅通过 stdin 提供。应用不会将输入内容拼进脚本源码。stdout 必须是 UTF-8，输出最大 4 MB。非零退出会停止后续步骤并显示 stderr；取消或超时会停止整个进程组，包括子进程。

例如使用 `/bin/zsh`，为每行增加前缀：

```sh
sed 's/^/TODO: /'
```

使用 `/usr/bin/python3` 格式化 JSON：

```python
import json, sys
print(json.dumps(json.load(sys.stdin), ensure_ascii=False, indent=2))
```

内置「整理文本」和「JSON 格式化」两个可编辑示例。流程脚本以当前用户权限执行，只配置自己信任的脚本。应用停止流程时也会清理后台子进程，不适合用作守护服务管理器。

### AI 帮写脚本

在「设置 → AI 助手 → 脚本生成模型」配置并保存：

- **Base URL**：例如 `https://example.com/v1`，自动拼接 `/chat/completions`；也支持完整接口地址。兼容 Chat Completions 协议的服务均可尝试接入。本地服务可用 `http://localhost:端口/v1` 或 `http://127.0.0.1:端口/v1`。
- **API Key**：单独保存在系统钥匙串。无鉴权的本地模型可留空。
- **模型名称**：填写服务支持的模型标识。

在流程步骤点击「AI 写脚本」，描述需求后生成；可修改生成结果，再点击「应用到步骤」，最后保存设置。模型只收到本次需求、该步骤的当前脚本、名称和解释器信息，不会自动收到剪贴板历史或其他文件。生成与应用均不会执行脚本；运行流程仍需主动触发。支持停止生成和错误显示，请按服务实际计费使用。

## 高级构建与界面预览

默认构建命令见 [README](../README.md)。只有在受限构建环境不允许 SwiftPM 启动子沙箱时，才需要使用：

```bash
WISP_DISABLE_SPM_SANDBOX=1 ./scripts/build-app.sh release
```

该选项仅影响构建工具；应用没有外部 SwiftPM 依赖。

检查界面时，可在独立预览模式中运行：

```bash
open -n build/Wisp.app --args --preview
```

预览模式使用临时独立数据目录、暂停剪贴板记录，不注册系统组合快捷键；连续按键仅在本应用内识别，也不执行后台唤起测试。退出预览实例后正常启动，才会使用正式数据目录。

构建与运行时验证的历史记录见 [验证记录](verification.md)。
