# 配置引导实施计划

**Goal:** 用户在应用内完成快捷键、权限和工具配置，知道当前可用范围并能验证后台唤起。

**Architecture:** 新增独立可观察的引导状态，单独保存引导进度，不改变用户业务配置。AppKit 管理引导窗口，SwiftUI 展示三步流程；共享权限检测与快捷键监听状态，真实后台触发才记为验证成功。

**Tech Stack:** SwiftUI、AppKit、ApplicationServices、现有 Carbon / NSEvent 监听。

1. 首次启动展示三步引导，支持稍后、完成与随时重新打开；记录已看和已完成状态。
2. 快捷键页展示当前三个入口与修改入口；权限页展示用途、真实状态、当前应用路径、系统设置入口和详细操作步骤。
3. 引导自动检测授权并刷新监听。提供后台唤起测试，区分未授权、已授权、监听已建立和已通过实际后台验证。
4. AI 页展示脚本模型、Codex 与豆包配置状态，链接到相应设置，允许跳过可选工具配置。
5. 主面板、菜单栏、设置均提供配置入口；保存权限相关功能时适时打开权限引导，避免重复弹窗。保留设置草稿，不因进入引导丢失未保存编辑。
6. Debug / Release 构建与临时冒烟检查，独立预览验证界面，不添加单元测试、不编译 Java。
7. 中文提交并推送 feature/261019-fj-setup-guide；默认不发布。此前已授权覆盖本机安装，验证后可更新已安装版本，保留用户数据。
