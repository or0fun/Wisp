# 连续按键与 AI 脚本生成实施计划

**Goal:** 快捷动作、剪贴板、流程支持同键双击和两键顺序触发；工作流程可调用自定义大模型生成脚本。

**补充范围：** 主界面动作列表直接包含已启用工作流程，传递当前输入执行，保留专用流程面板及关键词入口。

**计算器补充：** 输入公式自动在动作列表首位显示结果，回车复制。采用本地受限数学解析器，支持四则、括号、小数、负数、幂与百分数，不执行脚本；普通文本不触发计算。

**Architecture:** 组合快捷键沿用 Carbon；连续按键由本地/全局 NSEvent 监听和轻量状态机识别，仅保留按键代码与时间。模型配置使用可选 Codable 字段兼容旧配置，API Key 按用途分开存入 Keychain；统一 OpenAI 兼容 Chat Completions 客户端。

**Tech Stack:** SwiftUI、AppKit、Carbon、URLSession、Security。

## 行为与实现

1. 扩展 HotKey，保留原字段并添加可选第二按键。支持修饰键单独点击、两次普通键/组合键；双击为两个按键相同的特例。录制模式明确区分组合与连续按键。
2. 状态机要求完整按下/释放，忽略长按重复，超时、其他按键、鼠标或应用切换取消未完成序列。识别间隔可设置，默认 400 ms。普通输入仍交给当前应用。
3. 组合快捷键和连续按键检查重复及按键占用冲突。录制期间暂停全局入口，结束后恢复。连续按键跨应用需要辅助功能权限，设置内给出状态和入口，程序不自动授权。
4. 模型设置增加 Base URL、API Key、模型名称；支持 HTTPS 服务和本地 HTTP 模型。Base URL 自动拼接 `/chat/completions`；兼容直接填写完整接口。
5. 每个脚本步骤提供「AI 写脚本」。发送需求、当前脚本及解释器信息；展示可编辑结果，点击「应用到步骤」才替换当前脚本，生成与应用均不执行脚本。支持取消、超时和错误显示。
6. Debug / Release 编译、状态机与配置兼容冒烟、模拟模型服务、实际界面检查。不添加单元测试，不进行 Java 编译。
7. 中文提交并推送 `feature/261019-fj-shortcuts-ai`，不发布。
