# Wisp

把剪贴板、搜索、AI 与脚本工作流程，放进一个随时唤起的 macOS 面板。

Wisp 是一个受 Alfred 启发的原生 macOS 效率工具：找回刚才复制的内容，输入算式直接得到结果，把问题交给 AI，或用脚本处理一段文本。使用 SwiftUI + AppKit 构建，无第三方 Swift 包依赖。

> 应用名称与构建产物已统一为 **Wisp**。为兼容旧版，本地数据目录仍使用 `PersonalAI`，已有设置、剪贴板历史和钥匙串密钥继续沿用。

[使用与配置指南](docs/usage.md) · [反馈问题](https://github.com/or0fun/Wisp/issues)

## 功能

| 功能 | 可以做什么 |
| --- | --- |
| 剪贴板历史 | 按全部、文字、图片、文件分类，按内容或来源应用搜索，支持去重、置顶与预览 |
| 快捷搜索 | 内置 Google、百度、GitHub，支持关键词和自定义搜索地址 |
| 本机应用与文件 | 按名称查找已安装应用、文件与文件夹，直接打开或在 Finder 中定位 |
| AI 入口 | 打开豆包应用或网页；通过火山方舟 API 或本机 Codex CLI 在面板内获取结果 |
| 脚本工作流程 | 将多个脚本步骤串联，为流程设置关键词、独立快捷键与超时 |
| AI 写脚本 | 接入兼容 Chat Completions 的模型，描述需求后生成可编辑的脚本 |
| 实时计算 | 支持四则运算、括号、幂与百分数，回车复制结果 |
| 自定义快捷键 | 支持组合键、修饰键双击与连续按键，附首次配置引导和权限诊断 |

剪贴板和计算器可离线使用。AI 功能按需配置，使用它们需要相应的本机工具、账号或模型服务。

## 快速开始

### 环境要求

- macOS 14 或更高版本。
- Xcode Command Line Tools 或 Xcode，提供 Swift 工具链；项目声明的 Swift tools 版本为 5.9。

尚未安装命令行工具时，先运行 `xcode-select --install`，并等待安装完成。

### 从源码构建

```bash
git clone https://github.com/or0fun/Wisp.git
cd Wisp
./scripts/build-app.sh release
open build/Wisp.app
```

构建产物为 `build/Wisp.app`。建议将应用复制到 `/Applications` 后从固定位置使用，再配置系统权限。构建脚本只负责构建和签名，不会自动安装应用。

应用常驻菜单栏，不显示 Dock 图标。首次启动会打开配置引导；也可稍后从菜单栏重新进入。

当前以源码构建方式使用，默认采用本地 ad-hoc 签名，尚未提供经过 Developer ID 签名与公证的安装包。更新后可能需要重新授予辅助功能权限，处理方法见[使用指南](docs/usage.md#配置引导与后台诊断)。

## 开始使用

按 `⌥Space` 打开快捷动作，输入内容，用 `↑` / `↓` 选择动作，再按 `Return` 执行。

首页分为「快捷动作」「工作流程」「文件搜索」三列，共用上方输入框。匹配的本机应用排在快捷动作前面，文件与文件夹单独显示在第三列。可直接点击，也可用 `Tab` / `Shift Tab` 前后切列、`↑` / `↓` 在当前列选择、回车打开或执行；左右方向键仍用于编辑输入文字。

应用从 `/Applications`、`/System/Applications` 和 `~/Applications` 发现；文件按名称查询 macOS Spotlight 本机索引，不读取正文。文件结果显示所在路径，右键可在 Finder 中显示。未索引或无权访问的项目不会显示，详见[使用指南](docs/usage.md#本机应用与文件搜索)。

| 输入或操作 | 结果 |
| --- | --- |
| `(3+4)*2` | 显示 `14`，回车复制 |
| `100*20%` | 显示 `20` |
| `g macOS clipboard` | 用 Google 搜索 |
| `gh swift clipboard` | 在 GitHub 搜索 |
| `json {"hello":"world"}` | 执行内置 JSON 格式化流程 |
| 输入一段文本，选择豆包或 Codex | 将输入交给对应 AI 工具 |

内置「整理文本」和「JSON 格式化」流程均可编辑；示例使用 `/usr/bin/python3`，运行前请确认该解释器可用。

### 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 快捷动作 | `⌥Space` |
| 剪贴板历史 | `⌥⌘V` |
| 工作流程 | `⌥⌘Space` |
| 面板内切换动作 / 剪贴板 / 流程 | `⌘1` / `⌘2` / `⌘3` |
| 打开设置 | `⌘,` |
| 收起面板 | `Esc` |

可在设置中重新录制快捷键，包括 `⌘ → ⌘` 这样的双击触发。跨应用识别连续按键，以及自动粘贴到原应用，需要在「系统设置 → 隐私与安全性 → 辅助功能」中授权。

## 连接 AI 与自定义流程

- **豆包**：默认打开网页并将输入复制到剪贴板，需要手动粘贴和发送。可改为唤起本机应用，或配置火山方舟 API，在面板内显示结果。
- **Codex**：需要本机可用且已登录的 Codex CLI。应用会自动查找常见安装位置，也支持填写可执行文件的绝对路径。
- **AI 写脚本**：在「设置 → AI 助手 → 脚本生成模型」填写 Base URL、模型名称和可选 API Key。支持兼容接口的在线服务与本地模型；生成后可审阅、修改并应用到步骤。
- **工作流程**：在「设置 → 工作流程」中配置解释器与脚本。输入通过 stdin 传入，前一步的 stdout 会成为下一步的输入。

具体配置、脚本示例、连续按键规则和故障排查见[使用与配置指南](docs/usage.md)。

## 数据与使用边界

- **本地存储**：设置、剪贴板历史与图片保存在 `~/Library/Application Support/PersonalAI/`，未加密，不提供云同步。API Key 单独存入 macOS 钥匙串。
- **剪贴板记录**：默认开启，保留 300 条、30 天，容量上限 256 MB。可暂停、关闭或按应用排除；带隐私标记的内容会被跳过，未标记的敏感内容仍可能被记录。
- **外部服务**：执行搜索或 AI 动作时，相关输入会交给所选网站、CLI 或模型服务。AI 写脚本会发送本次需求及当前步骤信息，不会自动附带剪贴板历史。
- **脚本执行**：自定义流程以当前用户权限运行。AI 生成脚本不会自动执行，运行前请先审阅。
- **文件与格式**：文件历史保存路径引用，无法恢复已移动或删除的原文件；暂不支持富文本保留和 OCR。

当前为早期版本，尚无自动更新。已有 Apple Silicon 环境下的构建与运行验证记录，Intel Mac 尚未验证；具体覆盖范围见[验证记录](docs/verification.md)。
